# Автозапуск — обновления

Файлы обновлений для BLE-автозапуска на ESP32 и Android-приложения «Автозапуск».
Автор: «SMILE» Б.А.Н.

- `update.json` — описание последней версии (номера, ссылки, контрольные суммы SHA-256).
  Приложение проверяет его при запуске и предлагает обновиться.
- `releases/<версия>/` — файлы версии:
  - `Avtozapusk_<версия>.apk` — приложение для Android;
  - `firmware_<версия>_xiao_c3.bin` — прошивка для Seeed XIAO ESP32-C3;
  - `firmware_<версия>_esp32s3.bin` — прошивка для ESP32-S3 DevKitC-1.

Прошивку можно залить в плату только из приложения, знающего ключ машины;
плата проверяет контрольную сумму, поэтому чужой или повреждённый файл не установится.

Последняя версия приложения всегда: `releases/latest/Avtozapusk.apk`.

## Версии

- **17.2** (приложение и прошивка) — вкладка «Терминал» в сервисных настройках (в стиле «Матрицы»): журнал платы
  и телефона в одной ленте; переключатель «Диагностика» — плата копит подробный журнал в памяти (32 КБ), даже когда
  телефона нет рядом, при открытии вкладки всё накопленное приходит в телефон; живые значения (напряжение, входы,
  реле, сигналы, память), кнопки «Пауза», «Статус», «Фильтр», «Очистить», сохранение в .txt; значок «ДИАГ» на главном
  экране. Свой звук уведомлений «Звук Автозапуска» или стандартный. При первой установке — демо-режим (выход —
  нажатием на «ДЕМО»). Машина на главном экране вращается на 15 % медленнее.
- **17.1** (приложение и прошивка) — кнопка в машине срабатывает на выбор: от массы (как раньше) или от +3.3 В;
  тип светодиода: адресный WS2812 или обычный — на выводе появляется масса (светодиод горит), когда доверенный
  телефон в радиусе открытия машины (запуск разрешён), мигает при сопряжении и обновлении. Обычный светодиод:
  «плюс» к 3V3, «минус» через резистор 330 Ом…1 кОм к D9 (XIAO) или GPIO7 (ESP32-S3).
  Настройки: Сервис → «Запуск» → «Кнопка в машине» и «Светодиод».
- **17.0** (приложение) — сборка переведена на новые инструменты: Java 25 (JetBrains Runtime 25),
  Gradle 9.6, Android Gradle Plugin 9.4.1, Kotlin 2.4 (встроенный в AGP); внешне — как 16.10.
- **16.10** (приложение) — значок ручника: зелёный и когда затянут, и когда опущен (оба состояния нормальные);
  жёлтый при несовпадении — двигатель работает, а ручник затянут, или идёт запуск, а ручник опущен;
  красный 10 секунд, если запуск не состоялся из-за ручника, затем обычный цвет.
- **16.9** (приложение) — одна большая кнопка: «СТАРТ» по нажатию, «СТОП» удержанием 1 с (белая полоса
  по кольцу); остаток таймера автоотключения внутри кнопки; компактные значки датчиков; экран не прыгает;
  «Зажигание» — только в режиме ожидания; демо-режим (Сервис → «Система»); проверка обновлений,
  пока приложение на экране (раз в 30 минут).
- **16.5** (приложение и прошивка) — ушли с работающим двигателем: дверь не открывали — машина запирается,
  открывали — ждёт выключения зажигания; таймер автоотключения отменяется открытием двери, а не подходом;
  слайдер замка пишет, чего ждёт (двери или выключения зажигания).
- **16.3** (приложение) — слайдер замка вместо кнопок «Открыть/Закрыть» (цвет по состоянию); при отказе
  в запуске — конкретная причина; QR-код для скачивания приложения; кнопки без мерцания;
  убраны значки «Связь» и «Замок» из середины экрана.
- **16.2** (приложение) — фоновое подключение к машине: телефон сам подключается при подходе, даже с
  выключенным экраном, и отвечает плате на одноразовый вопрос; встроена прошивка 16.1.
- **16.1** (прошивка) — машина не закрывается, когда у телефона выключен экран: маячок спящего телефона
  принимается, пока плата слышит его без перерыва; после перерыва больше минуты снова нужна свежая подпись.
- **16.0** — релиз: финальная сборка приложения (release) и прошивки для XIAO ESP32-C3 и ESP32-S3;
  объединяет все изменения 15.x.
- **15.2** (приложение) — автоматическое подключение к машине при запуске приложения;
  отключается переключателем «Подключаться автоматически» в настройках.
- **15.1** — «Открывать при приближении» отдельно для каждого телефона; ответы на команды приходят
  только приславшему телефону; после смены ключа остальные телефоны отключаются.
- **15.0** — до 3 телефонов одновременно; дальний режим Bluetooth (Long Range), если телефон умеет;
  проверка и установка обновлений из приложения; приложение само отключается в фоне;
  исправлена модель машины на экранах.
