# Автозапуск — обновления

Файлы обновлений для BLE-автозапуска на ESP32 и Android-приложения «Автозапуск».
Автор: «SMILE» Б.А.Н.

- `update.json` — описание последней версии (номера, ссылки, контрольные суммы SHA-256).
  Приложение проверяет его при запуске и предлагает обновиться.
- `releases/<версия>/` — файлы версии:
  - `Avtozapusk_<версия>.apk` — приложение для Android;
  - `firmware_<версия>_xiao_c3.bin` — прошивка для Seeed XIAO ESP32-C3;
  - `firmware_<версия>_esp32s3.bin` — прошивка для ESP32-S3 DevKitC-1.

Прошивку можно залить в плату только из приложения, знающего ключ машины;
плата проверяет контрольную сумму, поэтому чужой или повреждённый файл не установится.

Последняя версия приложения всегда: `releases/latest/Avtozapusk.apk`.

## Версии

- **16.3** (приложение) — слайдер замка вместо кнопок «Открыть/Закрыть» (цвет по состоянию); при отказе
  в запуске — конкретная причина; QR-код для скачивания приложения; кнопки без мерцания;
  убраны значки «Связь» и «Замок» из середины экрана.
- **16.2** (приложение) — фоновое подключение к машине: телефон сам подключается при подходе, даже с
  выключенным экраном, и отвечает плате на одноразовый вопрос; встроена прошивка 16.1.
- **16.1** (прошивка) — машина не закрывается, когда у телефона выключен экран: маячок спящего телефона
  принимается, пока плата слышит его без перерыва; после перерыва больше минуты снова нужна свежая подпись.
- **16.0** — релиз: финальная сборка приложения (release) и прошивки для XIAO ESP32-C3 и ESP32-S3;
  объединяет все изменения 15.x.
- **15.2** (приложение) — автоматическое подключение к машине при запуске приложения;
  отключается переключателем «Подключаться автоматически» в настройках.
- **15.1** — «Открывать при приближении» отдельно для каждого телефона; ответы на команды приходят
  только приславшему телефону; после смены ключа остальные телефоны отключаются.
- **15.0** — до 3 телефонов одновременно; дальний режим Bluetooth (Long Range), если телефон умеет;
  проверка и установка обновлений из приложения; приложение само отключается в фоне;
  исправлена модель машины на экранах.
